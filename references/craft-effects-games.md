# Craft：动效材料与小游戏场景

只在用户任务需要高级动效或游戏交互时读取。这里是独立实现，不是官方 Pro 的私有实现，也不要求普通后台加入炫技效果。

## 三种可运行特效

入口：[动效材料](../examples/craft-effects/index.html)。HTML/CSS/JS 分离、无在线依赖。

- **SVG 流光**：stroke-dashoffset 沿明确路径运动，静态轨迹保留，不用假动画表示真实任务完成。
- **Canvas 点阵**：限制点密度与像素倍率；停止后保留当前画面；离开视口/页面隐藏不继续逐帧绘制。
- **WebGL 流动渐变**：真正的片元着色器，检查编译与链接；上下文不可用/丢失时切到静态 CSS 渐变并明确状态；恢复后重建资源。不要拿 CSS 降级截图当作 WebGL 实跑证据。

所有动态支持手动暂停与 prefers-reduced-motion；系统减少动态效果时默认静态，说明原因而不是悄悄启用。Canvas 是装饰层，文本、状态和操作仍用原生 HTML。不要申请额外付费服务，也不要为运行效果绕过组织的浏览器/GPU限制。

## 小游戏完整状态参考

入口：[记忆庭院](../examples/craft-game/index.html)。六组配对，原生按钮，键盘方向移动与 Enter/Space 翻牌。

| 状态 | 显示和行为 |
| --- | --- |
| 准备 | 选尝试次数，棋盘不可操作，开始按钮明确 |
| 进行 | 翻两张记一步，匹配保持，未匹配短暂展示后复位 |
| 待复位 | 锁住其他翻牌，防止第三张扰乱同一轮 |
| 暂停 | 遮盖棋盘并设 inert，保留计数与未结束的复位时间 |
| 胜利 | 六组全部配对，结果可见、焦点到结果，不继续计数 |
| 失败 | 用完尝试次数，结果明确，允许重新开始 |
| 重新开始 | 清理旧计时器、选中项和计数，生成新局 |

规则弹窗遵守模态键盘行为；关闭回触发按钮，已暂停的游戏由用户继续。页面隐藏自动暂停；无服务端、支付、排名或个人记录。完整示例不等于所有类型游戏的生产状态机。

## 精修与验证

先确定玩家目标、主要画布、状态和恢复方式，再决定渲染手法。检查窄屏操作尺寸、长说明、胜败后的下一动作、重复点击、暂停中计时器与重新开始残留。减少动态效果不能移除关键反馈；CSS zoom 与实际浏览器缩放分开记。

本环境已经验证 SVG/Canvas 与 CSS 降级、游戏胜败/暂停/重开。WebGL 实际渲染必须在具备支持的获准浏览器验证；当前机器的 CSS fallback 不可当其通过证据。

技术依据：原生 Dialog 键盘模式见 W3C APG；WebGL 上下文与绘制遵循浏览器标准 API。宿主缺独立评审能力时说明自查，不伪造其他 Agent 的评审结果。
