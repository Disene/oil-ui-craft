# Craft 原创组件原型：选择、实现与空间展开

> 本模块由 Disene Fork 独立开发；不包含官方 Oil UI Pro 的付费卡片源码，也**不把 6 套称为官方 19 套**。只在需要**高规格单组件设计、卡片布局或空间展开效果**时读取。

## 已有可运行参考

本仓库 [craft-cards/index.html](../examples/craft-cards/index.html) 是一个无外部服务依赖的 6 卡片对比页。HTML/CSS/JS 各独立文件，便于复制局部模式而不引入整个演示页面。六套布局的主结构不同，不是简单换肤：

| 设计原型 | 页面目标 | 构图取舍 | 重要状态 |
| --- | --- | --- | --- |
| Signal / 系统信号 | 一眼识别健康与异常 | 数值为主角、走势为证据、操作沉底 | 趋势 / 查看明细 |
| Ledger / 结算账单 | 准确识别金额与待核对项 | 纸张账簿、等宽数值、虚线分隔 | 资料齐备 / 未齐备 |
| Route / 流程节点 | 判断已经完成和下一步 | 纵向步骤轴 + 当前焦点 | 完成 / 正在进行 / 待开始 |
| Editorial / 编辑叙事 | 建立视觉记忆点 | 图像化构图和强标题，少量 CTA | 展开阅读 / 关闭 |
| Dispatch / 任务队列 | 按优先级进入处理 | 前景任务 + 退到背景的任务层 | 优先 / 待办 / 稍后 |
| Membership / 成员权限 | 识别谁能做什么 | 人员线索 + 显式双权限 | 允许 / 不允许 |

## 空间折展的可复用机制

示例脚本 `cards.js` 使用原生 `<dialog>` 承载**一套详情层**，按来源卡片填入合成数据，通过源卡片和 Dialog 的 DOMRect 计算展开动画的平移和缩放。打开时聚焦关闭按钮；Tab 留在原生 modal 内；Escape 或明确关闭后恢复到原触发按钮。浏览器声明减少动态效果时跳过展开动画。没有在图里放一个不工作的演示按钮，也没有引入需构建的 UI 框架。

**与业务实现分界**：示例数据全部合成，不可将此页面上“99.2%”“可发布”“已完成”等模拟事实直接复用到业务产品；业务权限、真实数值和保存回执必须从项目自己的数据合同取得。若项目已具备 Dialog、焦点管理或动画系统，优先复用它们，避免第二套组件基础设施。

## 使用路径

1. 确认当前任务是监控、结算、流程、编辑叙事、队列还是权限判断；不是这些任务就不必套卡片。
2. 从选中的结构里拿**版式和交互思路**，使用项目既有的字体、配色、token 与组件；让真实内容决定行高与密度。
3. 测默认、激活、展开、Escape/取消、返回焦点、窄屏、长文字和 reduced-motion 中实际涉及的状态；不要自动启动全站测试。
4. 打开真实渲染截图与按钮实际点击结果后才报告视觉与交互验证。静态代码通过不等于动效或业务成功。

验证脚本 `tests/test_craft_cards.py` 将原 HTML、CSS、JS 在内存中组合，供具备 Playwright 和 Chromium 的环境做本地合成浏览器测试；缺依赖时明确跳过，不绕过组织环境策略。若用户需要实际站点交互，仍应优先用其项目自带浏览器工具。

## 还没覆盖

当前只提供 **6 套原创构图**，不是 19 套；其他原创布局类型、高级 Shader/点阵/流光、完整游戏场景状态以及在真实业务产品中的验证均需要独立实施和验证。不要把其他旧原型目录计入本 Fork 的完成数。
