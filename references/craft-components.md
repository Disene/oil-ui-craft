# Craft 原创组件：十九种结构与可运行代码

本 Fork 的独立实现，不包含官方 Pro 的私有组件。**19 套原创模式不等于官方 19 套逐一复刻**。只在任务需要卡片、单组件精修或空间展开时读取；不把每个产品强制做成卡片。

统一入口：[交互参考](../examples/index.html)。无网络依赖，不携带真实业务数据。沿用项目既有组件和品牌，不把演示里的模拟数值当实际事实。

## 原型与可观察行为

| 编号 | 独立原型 | 主要结构与交互 |
| --- | --- | --- |
| 01 | Signal 信号 | 数值与走势主次分离，展开信号明细 |
| 02 | Ledger 账单 | 等宽金额与账簿分隔，展开待核对信息 |
| 03 | Route 流程 | 纵向阶段轴，展开步骤说明 |
| 04 | Editorial 叙事 | 图形主视觉与标题，空间展开阅读 |
| 05 | Dispatch 队列 | 前后层叠任务，展开优先级详情 |
| 06 | Membership 权限 | 显式双权限，展开与焦点返回 |
| 07 | Trend 趋势 | 周/月切换，同时更新数值、曲线和说明 |
| 08 | Quota 容量 | 滑杆驱动环形与文字，含临界/满额状态 |
| 09 | Booking 票券 | 时段选择→确认；未选择时不可确认 |
| 10 | Calculator 计算器 | 席位与年付切换，金额即时读回 |
| 11 | Kanban 任务 | 阶段推进与撤销，不新增真实任务 |
| 12 | Inline drawer 微抽屉 | 卡内展开/收起，非模态、不锁其他区域 |
| 13 | Compare 对照 | 语义滑杆调整前后结构占比 |
| 14 | Exhibit 画窗 | 手动轮播，按钮/键盘可达，无自动切换 |
| 15 | File 文件 | 本地名称/大小校验、错误、清除；不读取正文或上传 |
| 16 | Disclosure 分层说明 | 原生 details/summary，按需展开 |
| 17 | Checklist 准备清单 | 完成项计数与受条件约束的确认 |
| 18 | Combobox 搜索选择 | 方向键/Enter/Escape、无匹配、组字保护 |
| 19 | Preferences 设置 | 未保存、模拟失败保留输入、重试、还原 |

01–06 源码：[craft-cards](../examples/craft-cards/index.html)，独立 HTML/CSS/JS；07–19 源码：[craft-patterns](../examples/craft-patterns/index.html)，独立 HTML/CSS/JS。结构共享设计变量，交互按实际任务不同实现，不是十九次换色。

## 空间展开与迁移

六卡片继续复用同一原生 `<dialog>`，根据来源 DOMRect 计算 Web Animations API 的位移与缩放；关闭/Escape 回原按钮焦点，reduced-motion 跳过动画。第十二个组件是非模态卡内微抽屉，不使用模态焦点锁。

复制时提取需要的结构和状态，不整包植入第二个组件系统。字段、权限、保存/重试、错误定义服从业务项目已有合同。示例“确认”只改变当前页面状态，不冒充后端写入。

## 与其他能力联动

需要流光、点阵、着色器或游戏状态时读 [特效与游戏](craft-effects-games.md)。需要盲审时沿 [精修与评审](craft-polish.md)，可用 `scripts/review_packet.py` 准备去作者文件名和元数据的截图材料；该工具**不调用模型，不证明评审独立，不自动打分**。

## 验证边界

现有六卡片和新增十三模式均有完整静态页面的浏览器测试，覆盖具体交互、焦点、320–1440px 与 CSS 放大。真实 HTTP、原生浏览器缩放、读屏、触屏设备和真人业务效率必须分别验证；不能由静态示例的通过推定。源码、规则、可运行原型、自动测试和真实产品可用性是不同层级。
