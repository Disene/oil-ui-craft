MEMORY GARDEN

记忆庭院

翻开两张相同的植物。不是比速度，而是记住它们相遇的位置。

步数 0 / 18配对 0 / 6
准备进入庭院

选择挑战步数，然后开始。

尚未开始

留意每一次翻开

点击或按 Enter 翻牌。方向键移动焦点。匹配成功后，卡片会留在正面。

离开页面会自动暂停。所有状态只在本页保留，不记录个人资料。

怎样完成一局？

每次翻开两张算一步。找齐六组即获胜；用完步数则结束。暂停会遮住全部卡片，恢复后继续原局。

系统启用减少动态效果时，翻牌不依赖动画。
